# 🐍 Python Project Portfolio

Welcome! This repository contains a collection of dynamic, logic-driven applications built entirely using **Core Python**. These projects showcase my foundations in structural code design, looping automation, dynamic user interactions, and programmatic error troubleshooting.

## 🛠️ Applications Included

### 1. 📅 Interactive Contact Book & Database (`contact_book.py`)
* **Core Tech:** `while` loops, conditional structures (`if/elif/else`), nested lists, and dictionary data models.
* **Functionality:** Implements a text-based runtime loop allowing users to securely write (`add`) profile data maps and execute structured read loops (`view`) directly via terminal streams.

### 2. 🧮 Terminal Multi-Operator Calculator (`calculator.py`)
* **Core Tech:** Input data casting (`float()`), exception prevention boundaries, arithmetic operations.
* **Functionality:** Features continuous execution flows accepting keyboard prompts for numeric inputs and mathematical operations while protecting against application crashes through automated zero-division guards.

### 🎮 Automated Guess-The-Number Game (`guessing_game.py`)
* **Core Tech:** Module importation (`random`), iterative memory counters, search logic execution.
* **Functionality:** Features an algorithmic score tracking engine that monitors user trial iterations in real-time until a secret dynamic game state condition is resolved.
